- [ ] Push the complete project to a public GitHub repository.
- [ ] Confirm a fresh clone works with `pip install -r requirements.txt`.
- [ ] Run `python -m src.generate_data`, `python -m src.train`, `python -m src.evaluate`, and `pytest -q`.
- [ ] Record a five-minute pitch: problem, architecture, live API demo, metrics, and limitations.
- [ ] Demonstrate approve, review, and decline examples.
- [ ] State clearly that the included dataset and costs are synthetic/placeholders.
- [ ] Explain that the threshold is selected on validation data and metrics are reported on untouched test data.
- [ ] Confirm eligibility for the student-only, Bangalore in-person AI Builder Internship.
